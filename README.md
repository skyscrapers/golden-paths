# Skyscrapers Golden Paths

Example code and starter templates for the [Skyscrapers Golden Paths](https://docs.skyscrapers.eu/docs/golden-paths/).

## Contents

| Directory | Description |
|-----------|-------------|
| [starter/](starter/) | Cloneable starter template for a new service on the Skyscrapers platform. Includes Helm chart, Flux GitOps config, CI pipelines, and all golden path patterns (disabled by default). |

## Usage

Copy the `starter/` directory into a new repository, rename `my-app` to your service name, and follow the golden path documentation to enable the features you need.

See the [full documentation](https://docs.skyscrapers.eu/docs/golden-paths/) for details.
